### 👋 About me

Software developer from Puerto Rico building **local AI**, **automation** and **Linux** tooling — from bash scripts to multi-agent pipelines. My background in solar installation and industrial operations taught me to build things that are practical, safe and reliable.

- 🧠 **Local AI & agents** — Ollama, LM Studio, llama.cpp, RAG on ChromaDB/FAISS, Claude Code & OpenCode
- ⚙️ **Automation** — bots for nearly everything in Python, Bash and PowerShell, scheduled with systemd/cron
- 🐧 **Linux & systems** — Docker, SSH/GPG, UFW/fail2ban, WireGuard/Tailscale, custom multi-ISO USBs
- 🎮 **Games & creative** — game tweaks & scripting, Godot, Blender, FreeCAD, music production
- 📜 **Certified** — Python Pro (2025) · Programming & Computer Technology, 120h (2025)
